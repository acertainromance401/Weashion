공통 색상 토큰과 화면에 실제로 합성되는 면의 역할을 다룹니다. 하나의 토큰을 쓰더라도 배경·불투명도·역상 조건에 따라 최종 색이 달라집니다. 날씨 RGB와 3D 재질색은 공통 팔레트와 별도 책임입니다.

## 요소 분류와 책임

| 시각 요소 | 역할 | 변경 범위와 주의점 |
| --- | --- | --- |
| Paper / Ink | 기본 지면과 글자, 밝고 어두운 면의 대비 | 기본 토큰은 [01](#snippet-01), 전체 역할표는 아래 26.1 |
| Muted / Rule | 보조 정보와 얇은 구분선 | 설명과 단위가 읽히는지 확인. 장식선과 필수 경계를 구분 |
| Accent | 선택, 주요 행동, 포커스와 일부 번호 | 오류·주의·착용 적합성 판정색과 혼용하지 않음 |
| Warning / Error | 주의·지원 범위와 실패 | 색 외에 문구·아이콘으로도 상태 전달 |
| Stock / Studio | 입력·비교의 보조면과 중립 스튜디오 | 호출부마다 적용 비율이 다름 |
| 역상·국소 색 | 비 오는 표지, 어두운 소개, 도식과 3D | 공통 토큰 변경만으로 모두 바뀌지 않음 |

## 01. 종이색, 잉크색, 버건디를 공유하는 색상 토큰

원본: [EditorialStyle.swift / Editorial](../../weashion/weashion/Views/EditorialStyle.swift#L3)

```swift
static let paper = Color(red: 250 / 255, green: 249 / 255, blue: 246 / 255)
static let ink = Color(red: 32 / 255, green: 43 / 255, blue: 48 / 255)
static let muted = Color(red: 98 / 255, green: 107 / 255, blue: 103 / 255)
static let accent = Color(red: 159 / 255, green: 53 / 255, blue: 72 / 255)
static let warning = Color(red: 121 / 255, green: 81 / 255, blue: 23 / 255)
static let error = Color(red: 166 / 255, green: 41 / 255, blue: 32 / 255)
static let rule = ink.opacity(0.18)
static let stock = Color(red: 234 / 255, green: 231 / 255, blue: 224 / 255)
static let studio = Color(red: 236 / 255, green: 237 / 255, blue: 234 / 255)
```

- **역할:** 화면마다 임의의 색을 정하지 않고 잡지 같은 공통 인상을 유지합니다.
- **화면 효과:** 종이색 배경, 잉크색 글자, 버건디 선택 상태와 주요 행동, 얇은 구분선으로 표현됩니다.
- **수정 지점:** 전체 팔레트를 바꾸려면 이 토큰부터 봅니다. 다만 날씨 배경처럼 별도 색상을 가진 영역까지 자동으로 바뀌지는 않습니다.
- **주의:** 오류와 선택은 색뿐 아니라 문구, 아이콘, 선택 특성으로도 구분해야 합니다.

## 26.1. 팔레트 전체와 면의 합성

[26번 전체 분류](./design-principles.md#snippet-26)에서 이 문서로 옮긴 상세 표입니다.

| 토큰 | 값 | 눈에 보이는 역할 |
| --- | --- | --- |
| `paper` | `#FAF9F6` | 종이 같은 기본 바탕, 밝은 글자, 상태 안내 배경 |
| `ink` | `#202B30` | 본문·로고·구분선, 하단 내비게이션과 사이즈 노트의 어두운 면 |
| `muted` | `#626B67` | 출처, 단위, 부가 설명 |
| `accent` | `#9F3548` | 버건디 선택면, CTA, 측정 번호, 포커스와 헤더 스윕 |
| `warning` | `#795117` | 샘플·지원 범위·주의 안내. 착용 적합성 판정색이 아님 |
| `error` | `#A62920` | 입력 오류와 실패 |
| `rule` | Ink 18% | 장식용 얇은 경계 |
| `stock` | `#EAE7E0` | 입력면과 비교 정보의 보조 바탕 |
| `studio` | `#ECEDEA` | 3D 스튜디오와 상품 아트워크의 중립 배경 |
| 역상 조합 | Paper + Ink 또는 날씨의 어두운 배경 | 사이즈 노트, 소개, 비 오는 날의 표지 문자 |
| 지역 색상 | 날씨 RGB, 2D 도식 tint, 3D appearance, 시스템 primary/secondary/tint 및 일부 orange | 공통 토큰 외에 존재하는 별도 시각 표현 |

입력면의 Stock는 40%, 비교판은 45%, 상품 치수 버튼의 Accent 배경은 6%, 착장 슬롯 강조는 8%처럼 **호출부마다 다른 불투명도**를 사용합니다. 토큰 하나를 보고 모든 영역의 최종 색을 동일하게 해석하지 않습니다.

## 변경·검증 체크리스트

- 전체 팔레트 변경인지, 특정 호출부의 불투명도 변경인지 먼저 구분합니다.
- 밝은 지면과 Ink 역상, 비 오는 표지에서 글자·아이콘·선의 대비를 확인합니다.
- 선택·주의·오류를 색만으로 구분하지 않고 문구와 아이콘을 함께 유지합니다.
- Stock 40% 입력면, 45% 비교판, Accent 6%·8% 강조면을 같은 최종 색으로 취급하지 않습니다.
- 날씨 배경은 [20](./weather-graphics.md#snippet-20), 3D 의류·마네킹 외관은 [42](./rendering-and-gestures.md#snippet-42)와 [43](./rendering-and-gestures.md#snippet-43)을 별도로 확인합니다.
